# אפיון: סוכן ה-AI של שרה הלוי

סוכן AI ציבורי שעונה על שאלות על הניסיון של שרה מתוך תיק פרויקטים, עם מקורות לכל טענה, ומראה בזמן אמת איך כל תשובה נבנתה.

**סטטוס:** כל 12 הפרקים מאושרים (2026-11-03). השלב הבא הוא M1 (פרק 12).
