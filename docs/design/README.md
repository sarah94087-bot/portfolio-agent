# עיצוב הממשק

העיצוב נבנה ב-Claude Design ואושר ב-2026-11-05. **כיוון A** (אדום ושחור, Assistant ו-IBM Plex Mono) נבחר. כיוון B נשאר בארכיון.

- **ה-canvas החי:** https://claude.ai/artifact/VZcMM1sq8cyaVbpDeEXwHn
- **עותק מקומי של כל הלוחות:** [boards/](boards/). אלה קבצי `.dc.html` כפי שיצאו מ-Claude Design, והם נשמרו כאן כדי שהעיצוב לא יהיה תלוי בכלי. [boards/canvas.json](boards/canvas.json) הוא האינדקס.
- **הפרומפט שממנו נוצר:** [claude-design-prompt.md](claude-design-prompt.md)
- **מקור האמת של ה-tokens בקוד:** [apps/web/app/tokens.css](../../apps/web/app/tokens.css). הוא הועתק מהלוח `DS-Tokens`. אם משנים צבע, משנים אותו שם ולא ברכיב.

## החלטות

| נושא | החלטה | למה |
|---|---|---|
| גופן | Assistant (400–800) לטקסט, IBM Plex Mono למספרים, מזהי מודל, שמות כלים וציונים | הלטינית והעברית של Assistant נשרטו יחד, ולכן אין "קפיצת פונט" במשפט מעורב. ל-Mono יש `tabular-nums` כדי שעמודות ישתרו |
| גוף טקסט | עברית 18/1.8, לטינית 17/1.65 (דרך `:lang(he)`) | עברית בלי ניקוד צפופה ויזואלית |
| צבע | שחור-פחם `#151313` ואדום ארגמן `#C1121F` כצבע מותג יחיד. בכהה האדום הוא `#FF5C63` | דומיננטי ולא מתנצל. האדום עומד ב-5.5:1 על הנייר |
| פערים ושגיאות | פער הוא אפור-ניטרלי ומקווקו. מחיקה ושגיאה אמיתית הן שחורות. **אין אדום בפערים** | האדום הוא המותג, ולכן הוא לא יכול לסמן שגיאה. ההבדל עובר דרך צורה ומילה |
| עוצמת התאמה | צורה (עיגול מלא, חצי, מקווקו), מילה, ומספר כשיש | ברור גם בהדפסה בשחור-לבן וגם בלי צבע |
| פאנל עקבות | **inline-end**: משמאל בעברית, מימין באנגלית. מ-1100px הוא צמוד והעמודה נשארת 700px. בין 768 ל-1099 הוא נפתח מעל השיחה ברוחב 400px. מתחת ל-768 הוא מגירה תחתונה | בעברית הקריאה מתחילה מימין, ופאנל שם היה מזיז את נקודת העיגון של העין. אם רוצים ימין פיזי בשתי השפות, משנים `order` בקונטיינר |
| `aria-live` | אזור `role="status"` יחיד בראש בלוק התשובה. בזמן הזרמה הוא מכיל רק את סטטוס הכלי. הטקסט המוזרם הוא `aria-hidden`, וכשההזרמה נגמרת הטקסט המלא נכנס לאזור פעם אחת | הודעה אחת לכל תשובה, לא טוקן-טוקן |
| דיאגרמות | Mermaid תמיד `dir="ltr" lang="en"`, בתוך `<figure>` עם חלופה טקסטואלית. ה-themeVariables בלוח `Handoff` | |
| כיווניות | רק מאפיינים לוגיים (`ms-*`, `pe-*`, `start-0`). אייקונים עם כיוון מקבלים `.icon-dir` ומתהפכים ב-RTL. מונחים טכניים בתוך עברית עטופים ב-`<bdi class="mono">` | |
