# שחזור המסד

## מתי משתמשים
כשנתונים במסד של הפרודקשן נמחקו או השתבשו: מיגרציה שגויה, מחיקה ידנית בטעות, או סקריפט שכתב למקום הלא נכון.

**חלון השחזור בתוכנית החינמית של Neon הוא 6 שעות בלבד** (פרק 10, סעיף 2). אחרי זה אין לאן לחזור, אז פועלים מהר.

## מה אפשר לשחזר בלי Neon
- **בסיס הידע:** נבנה מחדש מ-git בכל פריסה (`python -m portfolio_agent.load`). מספיק להריץ את ה-deploy:
  https://github.com/sarah94087-bot/portfolio-agent/actions/workflows/deploy.yml
- **הטבלאות:** המיגרציות רצות בכל פריסה. הטבלה `schema_migrations` זוכרת מה כבר רץ, ומיגרציה שחסרה במסד ששוחזר רצה שוב.
- **שיחות, משוב ומונים:** אין גיבוי, בכוונה (פרק 10, סעיף 8). שחזור לנקודת זמן מחזיר גם אותם, ושיחות שהתקבלו אחרי נקודת השחזור הולכות לאיבוד.

## צעדים
1. **לעצור כתיבה למסד,** כדי שהנזק לא יגדל: לכבות את הסוכן (`kill-switch.md`). אם הנזק בא מ-workflow, לעצור אותו בעמוד הריצה עם **Cancel workflow**.
2. **לרשום את השעה שלפני הנזק,** ב-UTC. אפשר למצוא אותה בלוג של הריצה שגרמה לנזק, ב-Actions.
3. **לשחזר ב-Neon:** ב-https://console.neon.tech לבחור את הפרויקט `sarah-agent`, ואז **Restore**, ולבחור את הענף הראשי ואת השעה מסעיף 2. Neon שומר את המצב שלפני השחזור כענף נפרד, כך שאפשר לבדוק בו מה נמחק.
4. **להריץ את ה-deploy**, כדי שהמיגרציות ובסיס הידע יהיו עדכניים מול המסד ששוחזר.
5. **להדליק את הסוכן מחדש** (`kill-switch.md`).
